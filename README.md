Repositório da disciplina de **Compiladores (semestre 2026.2)**.

## Sobre o projeto

O projeto da disciplina é o desenvolvimento de um **transpilador** (compilador fonte-a-fonte):
um programa que lê código escrito em uma **linguagem de origem** e gera código equivalente em
uma **linguagem de destino**.
